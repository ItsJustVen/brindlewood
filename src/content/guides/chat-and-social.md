Everything for talking to other players and keeping your chat the way you like it.

## Commands

| Command | What it does |
| --- | --- |
| `/msg <player> <message>` | Sends a private message |
| `/msgtoggle` | Turns private messages on or off |
| `/ignore <player>` | Ignores a player. Run it again to stop ignoring them |
| `/list` | Shows who's online |
| `/near` | Shows players close to you |
| `/realname <nickname>` | Shows a player's real name behind a nickname |
| `/nick <name>` | Sets your nickname (unlockable) |
| `/emojis` | Shows the emojis you can use in chat |
| `/tags` | Opens your chat tags, the titles beside your name |

## Nicknames

`/nick` is an unlockable command. Get it free at character level 11, as a Knight, or buy it for 150 coins in the [CoinShop](/guides/coinshop). See [Character Levels](/guides/character-levels).

## Bedrock players

Add **BR_** before a Bedrock player's name, like `/msg BR_Steve hello`. See [Bedrock Players](/guides/bedrock-players).

## Staying comfortable

- Use `/ignore` if someone is bothering you, then tell staff in a ticket. See [Getting Help](/guides/getting-help).
- Use `/msgtoggle` when you don't want private messages.
- Read the [rules](/rules) so you know what's allowed in chat.
