Spend your coins on ranks, keys, boosters, commands and cosmetics. To open it, talk to the CoinShop NPC at spawn, or use `/coinshop`.

## Crate keys

| Key | Price |
| --- | --- |
| Common | 50 coins |
| Rare | 100 coins |
| Epic | 200 coins |
| Superior | 400 coins |

## Boosters

1 hour each, **200 coins** each: 2x Experience, 2x Level XP, and +20% Discounts. See [Boosters](/guides/boosters).

## Commands (permanent)

| Command | Price |
| --- | --- |
| `/disposal` | 100 coins |
| `/nick` | 150 coins |
| `/back` | 200 coins |
| `/craft` | 300 coins |
| `/feed` | 400 coins |
| `/enderchest` | 500 coins |

> Tip: you can unlock these for free by levelling. See [Character Levels](/guides/character-levels).

## Cosmetics (100 coins each)

Hats, particles, death effects, projectile effects, chat tags and tool skins. See [Cosmetics](/guides/cosmetics).

See [Pets and Mounts](/guides/pets-and-mounts) and [Horses and Stables](/guides/horses-and-stables).

## Ranks

Permanent and 30-day ranks. See [Ranks](/guides/ranks).
