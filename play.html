How to Play

Joining BrindleWood takes about a minute. Java and Bedrock players are both welcome.

Java Edition (PC)

  1. Open Minecraft Java and click Multiplayer.
  2. Click Add Server.
  3. Enter the address and click Done.
  4. Select BrindleWood and click Join Server.
