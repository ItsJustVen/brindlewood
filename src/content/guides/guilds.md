Guilds are groups of players who play, build and level together. They run on **BetterTeams**.

**Open it:** `/guild` (also `/guilds` or `/team`)

## Start a guild

1. Type `/guild create <name>`. Names are 2 to 12 characters.
2. Invite friends with `/guild invite <player>`.
3. They accept with `/guild join <guild name>`.

## Commands for every member

| Command | What it does |
| --- | --- |
| `/guild help` | Shows the commands you can use |
| `/guild join <guild>` | Joins a guild you were invited to |
| `/guild leave` | Leaves your guild |
| `/guild info [guild or player]` | Shows a guild's members and details |
| `/guild home` | Teleports you to the guild home |
| `/guild chat [message]` | Sends one message to guild chat, or switches guild chat on and off |
| `/guild allychat [message]` | Chats with your allied guilds only |
| `/guild warp [password]` | Teleports to the guild warp |
| `/guild echest` | Opens the guild ender chest |
| `/guild bal` | Shows the guild bank balance |
| `/guild deposit <amount>` | Puts money in the guild balance |
| `/guild top` | Shows the top guilds |
| `/guild baltop` | Shows the richest guilds |
| `/guild rank [guild]` | Shows a guild's rank |

## Commands for guild admins and the owner

| Command | Who | What it does |
| --- | --- | --- |
| `/guild invite <player>` | Admin and up | Invites a player |
| `/guild kick <player>` | Admin and up | Removes a member |
| `/guild ban <player>` / `/guild unban <player>` | Admin and up | Stops a player from joining |
| `/guild sethome` / `/guild delhome` | Admin and up | Sets or removes the guild home |
| `/guild setwarp [password]` / `/guild delwarp` | Admin and up | Sets or removes the guild warp |
| `/guild withdraw <amount>` | Admin and up | Takes money from the guild balance |
| `/guild pvp` | Admin and up | Turns pvp between guild members on or off |
| `/guild promote <player>` / `/guild demote <player>` | Owner | Changes a member's rank |
| `/guild title <player> <title>` | Owner | Gives a member a title |
| `/guild description <text>` | Owner | Sets the guild description |
| `/guild color` | Owner | Sets the guild color |
| `/guild open` | Owner | Lets anyone join without an invite |
| `/guild ally <guild>` / `/guild neutral <guild>` | Owner | Allies with a guild or goes back to neutral |
| `/guild name <name>` | Owner | Renames the guild |
| `/guild setowner <player>` | Owner | Hands the guild to someone else |
| `/guild disband` | Owner | Deletes the guild for good |

> Admins and the owner can also open the guild menu from `/guild` to manage the badge, members and settings by clicking.

## What you get

- Guild chat and ally chat
- Allies: up to 5 allied guilds
- Guild members can't hurt each other by default
- A guild bank at the Banker, which earns interest
- A shared guild ender chest and guild home
- Guild achievements
- A custom badge (patterns and borders)

## Guild bank

Your guild has its own bank account with the Banker. Deposits are tax-free and a small tax applies on withdrawals. The guild interest rate is fixed. See [Banks and the Banker](/guides/banks).

See [Guild Levels and Rewards](/guides/guild-levels) for how guilds grow.
