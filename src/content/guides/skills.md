You level skills by doing them. Every skill goes up to **level 100**.

| Skill | How you level it |
| --- | --- |
| Mining | Break ores and stone |
| Excavation | Dig dirt, sand and gravel |
| Farming | Harvest crops |
| Foraging | Chop trees |
| Fishing | Catch fish |
| Fighting | Fight mobs |
| Archery | Shoot things |
| Defense | Take hits |
| Agility | Run and jump around |
| Enchanting | Enchant your gear |
| Alchemy | Brew potions |

Skills go up from normal play, so just do what you enjoy.

## Commands

| Command | What it does |
| --- | --- |
| `/skills` | Opens your skills and levels |
| `/skilltree` | Opens the skill tree to spend points |
| `/levels` | Opens your character levels and rewards |
| `/leaderboards` | Shows the top players |

## Skill points and the skill tree

Every skill level-up gives you skill points, and the higher the level, the more you get:

| Skill levels | Points per level |
| --- | --- |
| 1 to 25 | 1 point |
| 26 to 50 | 2 points |
| 51 to 75 | 3 points |
| 76 to 100 | 4 points |

Spend them in the skill tree, which has several pages. Plan your path before you spend, and pick things that match how you actually play. A miner and a fighter should spend very differently.

Your skill levels and your character level are separate. Character levels are covered in [Character Levels and Rewards](/guides/character-levels).
