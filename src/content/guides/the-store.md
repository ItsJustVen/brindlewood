The store is optional. BrindleWood is built as support without buying the win. Almost everything sold can also be earned in-game, including claims and chunks.

[Open the store](https://brindlewood.tebex.io)

## What you'll find

- Coins (see [Coins](/guides/coins))
- Ranks (see [Ranks](/guides/ranks))
- Crate keys
- Fly Command
- Extra claims and chunks
- Premium races
- Furniture package
- Spawner Core

## Paid only

Three things can't be earned in-game:

- Premium races
- Fly Command
- Spawner Core (extra spawner permissions, since too many spawners cause lag)

Everything else is available in-game for free if you'd rather play for it.
