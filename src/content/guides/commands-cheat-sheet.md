Every command players can use, in one place. Type `/help` in-game to open the server guide menu. Most things also have a menu, so you can click instead of typing.

## Getting around

| Command | What it does |
| --- | --- |
| `/spawn` | Goes to Aldoria, the spawn world |
| `/rtp` | Opens the random teleport menu |
| `/warp` | Lists server warps. `/warp <name>` goes to one |
| `/warp rw` | Goes to the weekly resource world |
| `/pw` | Player warps (also `/pwarp` or `/playerwarps`) |
| `/home <name>` | Goes to one of your homes |
| `/sethome <name>` | Sets a home where you stand |
| `/delhome <name>` | Removes a home |
| `/homes` | Lists your homes |
| `/back` | Returns to where you died or last teleported from |
| `/map` | Opens the world map menu |
| `/near` | Shows players close to you |

## Teleporting to friends

| Command | What it does |
| --- | --- |
| `/tpa <player>` | Asks to go to them |
| `/tpahere <player>` | Asks them to come to you |
| `/tpaccept` / `/tpdeny` | Answers a request |
| `/tptoggle` | Turns teleport requests on or off |

## Your character

| Command | What it does |
| --- | --- |
| `/menu` | Opens your player profile |
| `/levels` | Your character levels and rewards |
| `/skills` | Your skills |
| `/skilltree` | Spend skill points |
| `/traits` | Your passive perks |
| `/achievements` | Your achievements |
| `/settings` | Your settings |
| `/playstyles` | Pick your playstyle |
| `/races gui` | Choose or view races |
| `/races classgui` | Choose a class |
| `/races info <race or class>` | Info about a race or class |
| `/races tree` / `/races classtree` | Evolution trees |
| `/races profile` | Your race profile |
| `/races leaderboard` | Race leaderboard |
| `/races questlist` | Lists race quests |
| `/races questview <quest>` | Reads a quest's description |
| `/races questprogress <quest>` | Shows your quest progress |
| `/races help` | Lists the race commands |
| `/leaderboards` | Server leaderboards |
| `/recipes` | Custom recipes you've unlocked |

## Money and shopping

| Command | What it does |
| --- | --- |
| `/balance` or `/bal` | Shows your money |
| `/baltop` | Richest players |
| `/pay <player> <amount>` | Sends money |
| `/trade <player>` | Starts a trade |
| `/ah` | Auction House (also `/auction`) |
| `/spawnershop` | Buy spawners |
| `/coinshop` | Spend coins |
| `/rewards` | Free hourly, daily and weekly rewards |
| `/kit` or `/kits` | Kits |
| `/vote` | Vote links |
| `/store` | Our store |

## Land and guilds

| Command | What it does |
| --- | --- |
| `/claim` | Claim land (see [Claiming Land](/guides/claiming-land)) |
| `/unclaim` | Gives up the claim you are standing in |
| `/claims` | Lists claims |
| `/guild` | Create or manage your guild (also `/guilds`) |

## Gear and storage

| Command | What it does |
| --- | --- |
| `/backpack` | Opens your backpack |
| `/enderchest` | Opens your ender chest (also `/echest` or `/ec`) |
| `/craft` | Opens a crafting table |
| `/disposal` | Opens a trash bin |
| `/recipe <item>` | Shows a recipe |
| `/minion` | Minions (`/minion myminions`, `/minion shop`) |
| `/pets` | Your pets |
| `/cosmetics` | Cosmetics menu |
| `/toolskins` | Tool skins |
| `/tags` | Chat tags |
| `/hiddenarmor` | Hides your armor (`toggle`, `hide`, `show`) |
| `/excellentenchants list` | Lists custom enchantments |
| `/feed` | Fills your hunger bar, if you've unlocked it |

## Chat and social

| Command | What it does |
| --- | --- |
| `/msg <player> <message>` | Private message |
| `/msgtoggle` | Turns private messages off |
| `/ignore <player>` | Ignores a player |
| `/nick <name>` | Sets a nickname |
| `/list` | Who's online |
| `/realname <nick>` | Shows a player's real name |
| `/emojis` | Emoji list |

## Links and help

| Command | What it does |
| --- | --- |
| `/link` | Links your Minecraft and Discord accounts |
| `/discord` | Discord invite |
| `/website` | Our website |
| `/rules` | Server rules |
| `/referral <username>` | Credit the friend who invited you |
| `/tutorial` or `/serverguide` | Opens the server guide |
| `/credits` | Server credits |
